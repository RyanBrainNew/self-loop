# Code Standards and Merge Gates

> Hard gates for this repository. A gate is actionable, checkable, and backed by
> repeated evidence. Product-specific rules belong in the project, not in the
> self-loop templates.

## Merge Gates

- [ ] Change is limited to the issue or explicit request.
- [ ] The relevant build, tests, lint, and type checks were run and recorded.
- [ ] Any check that could not run is marked **Not run** with the reason.
- [ ] Public behavior, compatibility, security, and data impact were considered.
- [ ] The pull request explains what changed and what was not verified.
- [ ] No pull request is merged and no default branch is pushed by the loop.
